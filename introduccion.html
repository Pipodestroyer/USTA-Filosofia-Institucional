    Introducción a Python

    "El asombro es el deseo de conocimiento."

    Aquí se te darán los recursos necesarios para completar el juego, desde simples metodologías hasta la creación de funciones, todo en el lenguaje de programación Python.

    1. Print (Imprimir en pantalla)

    La función print() es como el mensajero de Python. Se utiliza para mostrar información en la consola. Todo lo que pongas dentro de sus paréntesis será visible. Si quieres mostrar texto, debes rodearlo con comillas.

    Iniciando Pyodide. Esto puede tardar unos segundos la primera vez...

    2. def (Definir Funciones)

    La palabra reservada def sirve para crear una función. Imagina que es una receta de cocina: escribes los pasos una sola vez, le pones un nombre, y luego puedes "prepararla" (llamarla) tantas veces como quieras sin volver a escribir todo desde cero.

    Iniciando Pyodide. Esto puede tardar unos segundos la primera vez...

    3. Class (Clases y Moldes)

    Una class (clase) es como un plano de arquitectura o un molde. En lugar de crear las cosas una por una, creas un molde general que define la "esencia" (características y acciones) que tendrán todos los entes creados a partir de él.
